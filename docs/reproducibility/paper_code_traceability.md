# Paper-to-Code Traceability

## Status vocabulary

- **REPRODUCIBLE**: code, configuration, redistributable inputs, and command are present.
- **AUTHORISED INPUT REQUIRED**: executable code is public, but a dataset or checkpoint bundle must be obtained under its own terms.
- **FROZEN-OUTPUT REPLAY**: reported values and asset builders can be checked exactly from the included derived source tables; a from-scratch rerun additionally needs authorised inputs.
- **CONTEXT ONLY**: reported to motivate protocol choice and not treated as a replicate of the primary study.

All commands run from the repository root after `pip install -e '.[publication,dev]'`.

## Supplement coverage

The Supplement's study overview, notation, route coefficients, early comparisons,
full primary metrics, Roseworthy/RF/PI/Waite tables, sample construction,
redistribution, concentration, linkage robustness, SHAP–IG/Taylor quality,
stress/OOD tables, missing-modality details, agricultural cases, and four APSIM
tables map to P01–P34 above. No Supplement result is represented only by an
untraceable image: figure panels have source CSVs and manifests, while tables
either have a formal result CSV or an executable table builder. The remaining
legal boundary is access to the underlying restricted datasets and exact replay
bundle, not absence of modelling or analysis code.
