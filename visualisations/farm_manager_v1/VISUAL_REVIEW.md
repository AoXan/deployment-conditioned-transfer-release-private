# Visual Review

## Review conditions

- Reviewed at native 16:9 export size and in the 1920 x 1080 contact sheet.
- Reviewed in colour and grayscale.
- Checked PNG, SVG, and PDF availability for every static visual.
- Checked the animation for changing frames.
- Checked the interactive 3D file for an embedded Plotly runtime, anonymous
  paths, and explicit illustrative labelling.

## Findings

| Asset | Evidence class | Review result | Presentation boundary |
|---|---|---|---|
| V01 | Conceptual workflow | Pass | Describes a delivery process, not a measured effect. |
| V02 | Exploratory public context | Pass | Regional historical context is not a Seabrook forecast. |
| V03 | Formal result | Pass | SPATIAL improvement remains relative; absolute fit is limited. |
| V04 | Formal result | Pass | Three settings keep their native protocols and are not pooled. |
| V05 | Formal supplementary result | Pass | Paired intervals include zero; APSIM sensitivity changes ordering. |
| V06 | Formal diagnostics | Pass | Attribution and stress describe fitted-model behaviour, not causal effects. |
| V07 | Illustrative preview | Pass | Deterministic mock-up; prominently labelled as not a farm prediction. |
| V08 | Partnership proposal | Pass | Recommended pilot structure, not an experimental result. |
| V09 | Exploratory animation | Pass | Historical context only. |
| V10 | Illustrative 3D preview | Pass | Terrain and decision layers are synthetic and explicitly labelled. |

## Corrections made during visual QA

- Corrected the RF branch-average plot to use the formal `official_mae` field,
  matching the publication table generator.
- Wrapped the V01 column headings and long labels to remove collisions.
- Rebuilt the V08 phase cards to prevent heading overlap and baseline overflow.
- Changed contact-sheet generation from crop-to-fit to contain-with-padding so
  no labels are cut from thumbnails.

## Final decision

All assets are suitable for a farm-manager discussion when the evidence badge
and footer boundary are kept visible. V07 and V10 must never be presented as
farm-specific outputs before a local pilot has supplied and validated the
required data.
